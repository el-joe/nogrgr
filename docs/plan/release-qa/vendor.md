## Steps / expected / actual

### RQA-VEN-001
1. Register a new store, open Setup wizard › Languages, a priced language is listed (French $5.00).
2. Pay with Stripe test card 4242 4242 4242 4242 → payment captured (payment_logs #5), add-on purchase #1 paid, translation run #1 starts.
3. Back on the wizard step: French is still offered with the card form and "Buy for $5.00". Pay again → payment_logs #6 captured, add-on purchase #2, translation run #2 queued.
- Expected: once paid (purchase paid / run queued or translating) the language shows "Paid — translating" (as Settings › Languages does) and cannot be bought again; the server refuses a second purchase of the same language.
- Actual: `LanguageService::availableToPurchase()` only excludes languages already active on the store (`tenant_languages`), not paid-but-not-yet-activated purchases.
